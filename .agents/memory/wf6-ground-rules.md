## Source of truth

**Only sheet "3. Content Wireframe" in `Aeolus-Wireframe-06.xlsx` is authoritative.**
- Sheet 1 "Support" = personal/dev notes. Contradicts sheet 3 in places. Ignore for product decisions.
- Sheet 2 "Master Tire Specs" = marketing team notes. Also contradicts sheet 3. Ignore for product decisions.

## Tire count

**45 tires**, exactly matching sheet 3 row-by-row. This is the correct number — do not reduce or expand it without a sheet 3 edit + regenerate.

## `tires.generated.ts` is READ-ONLY

- Lives at `artifacts/aeolus-website/src/data/tires.generated.ts`
- Auto-generated by `scripts/generate-tires.py` from sheet 3
- Regenerate: `pnpm --filter @workspace/scripts run generate:tires`
- **Never hand-edit it** — any change will be overwritten on next regenerate
- If a tire looks wrong, fix it in the spreadsheet, then regenerate

## Canonical data flow

```
Aeolus-Wireframe-06.xlsx (sheet 3)
  → scripts/generate-tires.py
    → src/data/tires.generated.ts  (read-only)
      → src/data/tires.ts          (re-exports; add hand-maintained companions here)
```

## imgs/ directory

Tracked in git on purpose — it is the handoff channel between Replit, Claude's local machine, and GitHub. Do not add it to `.gitignore`.

**Why:** Cross-environment image sharing requires a committed path; .gitignore would break the workflow.

**How to apply:** When you see new files appear in `imgs/`, they are intentional drops from the client or Claude's local session. Copy/move them to the appropriate `public/tires/` subdirectory as needed.
